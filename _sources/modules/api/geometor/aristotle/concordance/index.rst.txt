geometor.aristotle.concordance
==============================

.. py:module:: geometor.aristotle.concordance

.. autoapi-nested-parse::

   Bekker coordinate parser and cross-corpus Aristotle concordance builder.

   Scans ``geometor/euclid``, ``geometor/hoenen``, and ``geometor/pacioli`` (when present
   in the sibling workspace) to construct a unified Bekker concordance linking every cited
   Aristotelian passage back to exact sister-project volumes, pages, folios, chapters, and
   display strings, as well as forward to the corresponding unit and Bekker anchor in
   *Loci Geometrici et Noetici*.

.. py:class:: ConcordanceEntry

   Aggregated concordance record for a distinct Aristotelian Bekker locus.

   :ivar locus_id: Unique canonical identifier (e.g. ``"anal-post:77b30"``).
   :ivar bekker: Normalized ``BekkerRef`` sort/display object.
   :ivar bekker_display: Human-readable Bekker span (e.g. ``"77b30"``).
   :ivar work_id: Canonical treatise slug (e.g. ``"anal-post"``).
   :ivar work_la: Latin treatise title.
   :ivar work_en: English treatise title.
   :ivar book: Book number if resolved, else ``None``.
   :ivar chapter: Chapter number if resolved, else ``None``.
   :ivar chapter_display: Formatted book.chapter label (e.g. ``"I.12"``).
   :ivar in_codex: Whether this locus is included in the primary text of *Loci Geometrici*.
   :ivar codex_unit: Target unit directory/file slug if ``in_codex`` is ``True``.
   :ivar codex_unit_title: Short title of the Codex unit if ``in_codex`` is ``True``.
   :ivar codex_anchor: Sphinx anchor label (e.g. ``"bekker-77b30"``) inside ``-en.rst``.
   :ivar repos: Sorted list of sister repositories citing this locus.

.. py:function:: parse_bekker_locus(text: str, page_range: tuple[int, int] = (1, 1500)) -> BekkerRef | None

   Extract a canonical ``BekkerRef`` from a raw locus or display string.

   :param text: Raw locus token or citation display string (e.g. ``"I.2.72a14-24"``,
                ``"i-10-76-b-9"``, ``"Metaph. 1051 a 24"``, ``"1014a35-b5"``).
   :param page_range: Inclusive ``(min_page, max_page)`` bounds used to disambiguate
                      treatise page numbers from book/chapter numbers.

   :returns: Parsed ``BekkerRef`` if a valid Bekker coordinate within ``page_range`` is
             found, otherwise ``None``.


.. py:function:: match_codex_unit(work_id: str, book: int | None, chapter: int | None, bekker: BekkerRef) -> tuple[geometor.aristotle.units.UnitSpec, geometor.aristotle.units.ChapterSpec] | None

   Match a resolved Aristotelian citation to its ``(UnitSpec, ChapterSpec)`` in the Codex.

   :param work_id: Canonical work identifier.
   :param book: Book number or ``None``.
   :param chapter: Chapter number or ``None``.
   :param bekker: Normalized ``BekkerRef`` coordinate.

   :returns: Matching ``(UnitSpec, ChapterSpec)`` if the locus is covered by Libri I–V,
             otherwise ``None``.


.. py:function:: build_concordance(repo_root: pathlib.Path, workspace_root: pathlib.Path | None = None) -> dict[str, Any]

   Mine Aristotle citations across GEOMETOR sister repos and write ``concordance.json``.

   :param repo_root: Root directory of ``geometor/aristotle``.
   :param workspace_root: Optional parent ``geometor`` directory containing ``euclid``,
                          ``hoenen``, and ``pacioli``. Defaults to ``repo_root.parent``.

   :returns: Complete concordance dictionary written to
